# Issue tracker: GitHub

Issues and specs live in GitHub Issues for emerald-pham/funsidething. Use the gh CLI from this repository.

Publish one issue per approved ticket. Read the full issue body and comments before work. Use native issue dependencies for blocking edges; fall back to an explicit Blocked by list if unavailable. Use native sub-issues only when a source parent issue exists. Do not close or modify a source parent merely to publish its tickets.

Use a UTF-8 body file for multiline issue, comment and PR text. Resolve labels through triage-labels.md. Existing repository authorization, coordination and release rules remain authoritative.

PRs as a request surface: no.
